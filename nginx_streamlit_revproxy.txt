How to enable streamlit service using nginx reverse proxy for browser or internet access.1. Create systemd service files

For each app, create a unit file in /etc/systemd/system/

sudo nano /etc/systemd/system/st_shortlist_app.service
sudo nano /etc/systemd/system/st_fnoreport_app.service
sudo nano /etc/systemd/system/st_indiceschg_app.service

Example content (adjust script, port, and baseUrlPath per app):
[Unit]
Description=Streamlit App for stock shortlisting
After=network.target

[Service]
User=shail
WorkingDirectory=/home/shail/stockshortlisting
ExecStart=/usr/bin/python3 -m streamlit run /home/shail/stockshortlisting/shortlist_stockanalysis.py --server.port 8501 --server.headless true --server.baseUrlPath shortlist
Restart=always
Environment="PATH=/home/shail/.local/bin:/usr/bin:/bin"

[Install]
WantedBy=multi-user.target


2. Reload systemd and start services
sudo systemctl daemon-reload
sudo systemctl start st_shortlist_app.service
sudo systemctl start st_fnoreport_app.service
sudo systemctl start st_indiceschg_app.service

Check status:
systemctl status st_shortlist_app.service
systemctl status st_fnoreport_app.service
systemctl status st_indiceschg_app.service

3. Enable auto‑start on boot
sudo systemctl enable st_shortlist_app.service
sudo systemctl enable st_fnoreport_app.service
sudo systemctl enable st_indiceschg_app.service

4. Configure Nginx reverse proxy
Edit /etc/nginx/sites-available/streamlit:
server {
    listen 80;
    server_name 4.188.224.16;

    location /shortlist/ {
        proxy_pass http://localhost:8501/shortlist/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location /fnoreports/ {
        proxy_pass http://localhost:8502/fnoreports/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }

    location /indiceschg/ {
        proxy_pass http://localhost:8503/indiceschg/;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection "upgrade";
        proxy_set_header Host $host;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    }
}

Enable the site:

5. Test and reload Nginx
sudo nginx -t
sudo systemctl reload nginx

6. Verify access

Open in browser:

    http://<server-ip>/shortlist/

    http://<server-ip>/fnoreports/

    http://<server-ip>/indiceschg/
